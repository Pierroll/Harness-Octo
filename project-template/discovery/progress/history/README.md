Una nota por sesión de trabajo, en orden cronológico. No se editan después de escritas:
si algo salió mal, se corrige en la nota de la sesión siguiente.

El nombre del archivo es `<YYYY-MM-DD>-<n>-<tema>.md`, donde `<n>` es el número de
sesión de ese día. Lo crea `harness/skills/session-log/` al cerrar.
