# Paquete heredado — etapa 2

Usa esta carpeta **solo si este proyecto no corrió la etapa 1**. Es la bandeja de
entrada: dejas aquí lo que traes de un discovery previo, de la propuesta o del cliente.

`entry-check` mira aquí primero. Si el archivo sirve, lo **copia** a su sitio de
trabajo. Esta carpeta no se edita después: queda como
constancia de con qué se abrió la etapa.

Un README o un archivo con `<placeholders>` no cuenta.

| Archivo (nombre fijo) | Qué es | Sitio de trabajo después del chequeo |
|---|---|---|
| `gaps-and-risks.md` | Temas por entender, supuestos, riesgos, temas por negociar | `discovery/2-analysis/outputs/gaps-and-risks.md`, marcado como viene (borrador o validado) |
| `as-is.md` | Cómo trabajan hoy, aunque sea tentativo | `discovery/2-analysis/outputs/as-is.md`, marcado tentativo hasta que la etapa lo valide |
| `to-be.md` | Cómo debería quedar, aunque sea tentativo | `discovery/2-analysis/outputs/to-be.md`, igual que el As-Is |
| `session-calendar.md` | Sesiones con dueño del cliente y fecha. Si solo tienes el `.docx` de agendas, déjalo aquí con ese nombre o como `Discoveries.docx` | se queda aquí; no se finge como salida de la etapa 1 |
| `backlog.md` | Módulos (o features) de lo que se va a construir | `backlog.md` en la raíz, si el de la raíz sigue vacío |

Los transcripts **no van aquí**. Van un nivel arriba, como `d<N>-transcript.md`.

Si falta alguno, no lo inventes. `entry-check` lo marca hueco y se produce un recorte
de la etapa 1 sobre eso, no la etapa entera.
